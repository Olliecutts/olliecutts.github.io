Thoughtful replies, with strict limits.

King Chilli Comment Starter is an internal tool operated by King Chilli The Pug. It uses the official YouTube API to identify a very narrow class of positive comments on our own videos and, when separately activated and authorised, post a response from a fixed collection of pre-approved replies.

What the application does

The YouTube pilot is limited to short, unambiguous, positive emoji-only reactions. It does not generate new replies with AI, handle questions or sensitive topics, or reply automatically to ordinary written comments.

Before any response, the application checks the authorised channel, ownership of the video, existing replies, timing and rate limits. It records a durable send intent before the one permitted submission. If the result is uncertain, it stops rather than trying again.

The pilot is initially limited to a maximum of five reply attempts in a rolling 24-hour period. The application has a separate pause control and is not a public chatbot.

Who can use it?

Only the authorised King Chilli channel operator. There is no public sign-up, visitor account, or payment service.

What access does it use?

YouTube API access authorised through Google's OAuth consent process to read channel, video and comment information and post limited replies on the connected channel.

Data and consent

This application uses YouTube API Services. Access is granted by the channel owner via Google OAuth, can be revoked from Google Account connections, and is used solely for the functions described above. This website itself does not collect Google passwords or offer an OAuth login form.

Details of the data processed, privately retained and deletion requests are in our Comment Starter Privacy Notice. The operator terms are available in our Terms of Use.
